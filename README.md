# MealsApp
Project Link : https://abslan.github.io/MealsApp/

🍽️ Meal Explorer App

A responsive, single-page meal search application built using HTML, CSS, and Vanilla JavaScript, powered by the TheMealDB API. No JavaScript frameworks or libraries were used.

🔍 Features

Live Search: Search for meals as you type, with real-time suggestions.
Meal Details View: View detailed information about selected meals (name, photo, instructions).
Favorites: Add or remove meals from a favorite list, with data persisted using localStorage.
Single Page Layout: Used collapsible tabs and dynamic DOM manipulation to simulate page navigation—no routing or external libraries used.


🧩 Tech Stack

- HTML5  
- CSS3  
- Vanilla JavaScript  
- TheMealDB API  
- localStorage for persistence
